# P04-SEG-01 | Segmentación de clientes para la gestión logística

## 1. Descripción del proyecto

Este proyecto tiene como finalidad desarrollar una solución basada en ciencia de datos que permita segmentar clientes de acuerdo con sus características y comportamientos, con el propósito de apoyar la toma de decisiones y mejorar la gestión logística.

Se desarrolla un enfoque de aprendizaje no supervisado mediante K-Means, complementado con un modelo de clasificación Random Forest para facilitar la asignación de nuevos clientes a los segmentos identificados.

## 2. Objetivo del proyecto

Desarrollar un modelo de segmentación de clientes que permita identificar grupos con características diferenciadas y proporcionar información útil para la planificación y toma de decisiones logísticas.

## 3. Metodología

El desarrollo contempla las siguientes etapas:

- Exploración y análisis de los datos.
- Preprocesamiento y transformación de variables.
- Aplicación del algoritmo K-Means.
- Evaluación y comparación de resultados.
- Caracterización de los segmentos identificados.
- Implementación de un modelo Random Forest para clasificar nuevos registros.

## 4. Tecnologías utilizadas

- Python
- Google Colab
- Pandas y NumPy
- Scikit-learn
- Matplotlib y Seaborn
- GitHub

## 5. Modelos implementados

**K-Means:** utilizado para identificar segmentos de clientes mediante aprendizaje no supervisado.

**Random Forest:** utilizado como modelo complementario para clasificar nuevos clientes según los segmentos previamente identificados.
